# ReMap — North Jersey Regional Planning Lab

**ReMap is an interactive project exploring how regional planning choices could affect access to jobs, transportation, and opportunity across North Jersey.**

The project starts with a simple question:

> What if we planned around how people travel, work, and access services—not only around existing municipal boundaries?

## Project goals

- Explore how towns relate to one another through commuting and access to jobs.
- Let users experiment with proposed regional groupings.
- Model possible investments in transit, jobs, and local connections.
- Compare a baseline scenario with a proposed scenario.
- Make regional planning understandable through an interactive map.

## Current prototype

The current browser-based prototype includes:

- An interactive map with 10 North Jersey town centers.
- Clickable towns with demo population, jobs, and transit-access information.
- Three proposed planning regions (A, B, and C).
- Controls to assign towns to different regions.
- Illustrative investments for train station upgrades, express buses, jobs hubs, and walking/cycling links.
- A simple dashboard for estimated commute time, job-access index, and budget.
- A $500 million demonstration budget.

### Towns currently included

Fair Lawn, Ridgewood, Paramus, Hackensack, Teaneck, Englewood, Fort Lee, Clifton, Paterson, and Newark.

## How to try it

1. Open the published ReMap website (once GitHub Pages is enabled).
2. Click a town marker to inspect its information.
3. Select one or more towns and assign them to Region A, B, or C.
4. Add an investment to a town.
5. Click **Run simulation** to update the dashboard.
6. Use **Reset entire scenario** to start again.

## Important limitations

This is an early prototype, not a validated planning model.

- Town markers use town-center locations; the colored zones are approximate proposed regions, not official municipal boundary polygons.
- Population and jobs figures are illustrative or approximate.
- Commute and job-access changes are generated by simple demonstration formulas. They are not official forecasts and should not be used to make real policy decisions.
- Changing a boundary alone does not physically shorten a commute. In a realistic model, outcomes would depend on how regional coordination changes decisions about transit, housing, jobs, and services.
- The map uses online map tiles and a mapping library, so an internet connection is required.

## Planned improvements

1. Add official municipal boundary data.
2. Replace demonstration values with sourced population, employment, and transit data.
3. Incorporate real home-to-work commuting flows.
4. Improve the simulation so assumptions are transparent and outcomes are explainable.
5. Add comparisons between the current arrangement and user-designed scenarios.
6. Improve accessibility, mobile layout, and project documentation.

## Contributing ideas

Suggestions and feedback are welcome. Useful contributions include reliable data sources, ideas for clearer visualizations, ways to test model assumptions, and improvements to the interface.

## Project principle

**Make assumptions visible. Separate real data from estimates. Treat simulated outcomes as hypotheses to explore—not as facts.**
